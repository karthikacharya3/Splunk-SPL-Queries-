# Successful Logins Attempts 

## Objective :
Detect successful Windows authentication attempts.

# SPL Query
index=* EventCode=4624
| stats count by user src_ip
| sort -count

## Sample Use Case :
SOC analysts use this query to identify successful logins 

## Expected Output :
•⁠  ⁠Username
•⁠  ⁠Source IP
•⁠  ⁠Number of successful attempts
