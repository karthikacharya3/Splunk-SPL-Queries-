# Splunk SPL Queries

This repository contains practical Splunk Search Processing Language (SPL) queries that I developed while practicing Security Operations Center (SOC) investigations using Splunk Enterprise.

## Topics Covered

- Failed Login Attemptd ( Windows Eventid=4625)
- Successful Login (Windows Eventid=4624)
- Top Source IP's
- Top Firewall Deny Events 
- Top Destination Ports 
- Most Active Users 
- Brute Force Detection
- New Process Creation
- Large Data Transfer
- Connections To Many Destinations 

## Tools Used

- Splunk Enterprise
- Windows Event Logs
- Fortinet Firewall Logs

- Threat Detection
- Incident Investigation
