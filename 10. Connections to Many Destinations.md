# Connections to Many Destinations

## objective :
To findout which all source ip's have been connected with the how many unique destination ip's 

# SPL Query :
vendor_product="Fortinet Firewall"
| stats dc(dest_ip) as destinations by src_ip
| where destinations > 60

## use case
 SOC analyst use this query to find out which all source ip's are connected to how many unique destination ip's
